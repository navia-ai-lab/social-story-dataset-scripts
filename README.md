# Social Story Dataset Scripts

Collection of scripts for generating clinically acceptable Social Stories.

## Getting Started

1. Clone the repo
    ``` bash
    git clone https://github.com/navia-ai-lab/social-story-dataset-scripts
    cd social-story-dataset-scripts
    ```

2. Create venv
    ```bash
    uv venv
    source .venv/bin/activate
    ```

3. Install dependencies
    ```bash
    uv sync
    ```
